# Kapsalon Dana

Website voor Kapsalon Dana ✂, Naamsesteenweg 71, 3001 Heverlee (Leuven). Kapper voor heren, dames en kinderen.

## Gegevens van de zaak (verzameld 6 okt 2026)
- Telefoon: 0488 29 26 29 · BTW 0812.124.580 (van hun prijslijst)
- Google: 4,9★ uit 151 reviews, geen website (alleen een Facebook-pagina)
- Uren (Google): di–vr 10–19, za 10–18, zo 9–17, maandag gesloten
- Prijzen: volledig overgenomen van de prijslijst in de zaak (foto op Google Maps, `img/raw/g01.jpg`)
- Kenmerken uit reviews: zonder afspraak, snel, prijsvriendelijk, veel gezinnen met kinderen

## Design
Licht en warm (crème, koraal, donkerblauw), zodat het duidelijk verschilt van de donkere barbersites. Opgebouwd rond "Men / Women / Children", zoals op hun raam.
